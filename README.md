# Wordle

A Wordle clone built with Next.js, TypeScript, and Tailwind CSS. It runs on its own and also shows up on my portfolio at `/wordle`.

- **Daily mode**: everyone gets the same word each day. Progress and stats (win %, streaks, guess distribution) are saved in your browser.
- **Unlimited mode**: a new random word every game, just for practice. It doesn't count toward stats.

## How it's put together

| File | What it does |
|---|---|
| `lib/words.ts` | Hand-picked answer words, and the combined set of valid guesses |
| `lib/guesses.ts` | Every 5-letter word from the public-domain ENABLE list. Generated by `node scripts/build-guesses.mjs`, so don't edit it by hand |
| `lib/game.ts` | Game rules: scoring a guess, picking the daily word, keyboard colors |
| `lib/storage.ts` | Saving stats and today's progress in localStorage |
| `components/Game.tsx` | Game state and input handling |
| `components/Board.tsx`, `Keyboard.tsx`, `StatsModal.tsx` | UI pieces |
| `app/page.tsx` | Loads `Game` in the browser only (it needs localStorage) |

## How it connects to the portfolio

`next.config.ts` sets `basePath: "/wordle"`, so every page and asset of this app lives under `/wordle/...`. This app is deployed as its own Vercel project, and the portfolio's `next.config.ts` has a rewrite that forwards `/wordle/*` requests to this deployment. To visitors it looks like one site; in code, the two repos stay independent.
